# Ластик-взрыватель 💣 для Safari (урок 2)

Юзерскрипт для приложения **Userscripts**. Внизу слева появляется кнопка 💣:
нажмёшь, и она станет красной. Теперь нажимай на что угодно на сайте, и оно взорвётся.
Нажми 💣 ещё раз, чтобы выключить режим. Обнови страницу, и всё вернётся.

## Установка
Открой в Safari ссылку и нажми значок пазла → **Userscripts** → **Install**:
https://raw.githubusercontent.com/rosaveskimae8/vibe-coding/main/lesson-02/boom-eraser-safari/boom.user.js
