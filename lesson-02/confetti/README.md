# Конфетти 🎉 (урок 2)

Нажимаешь на значок расширения, и по странице летит конфетти с фруктами.
Горячая клавиша: **Alt + Shift + C**.

## Файлы
- `manifest.json` — «паспорт» расширения
- `background.js` — ждёт нажатия на значок и вставляет конфетти в открытую вкладку
- `confetti.js` — сама анимация: рисует бумажки и фрукты на прозрачном холсте поверх страницы

## Как установить в Chrome
1. Открой `chrome://extensions` и включи **Режим разработчика**
2. **Загрузить распакованное** → выбери папку `confetti`
3. Закрепи значок булавкой

Версия для Safari лежит в папке `confetti-safari`.
