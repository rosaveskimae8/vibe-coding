# Утиный режим 🦆 (урок 2)

По сайту гуляет утка: качается при ходьбе, крякает со звуком,
а иногда подходит к какому-нибудь куску сайта, кричит «Моё! 😈» и утаскивает его за край экрана.
Нажми на утку: она крякнет и подпрыгнет. Обнови страницу, и утащенное вернётся.

Выпустить или убрать утку: значок расширения или **Alt + Shift + D**.

## Как это устроено (`duck.js`)
- Звук «кря» не берётся из файла, его рисует синтезатор Web Audio: пила 620→330 Гц через фильтр.
- Утка всё время находится в одном из трёх режимов: `walk` (гуляет), `hunt` (идёт к добыче) и `escape` (убегает с добычей).
- Чтобы утащить кусок сайта, скрипт делает его копию (`cloneNode`), которую несёт утка, а оригинал прячет.

## Установка в Chrome
`chrome://extensions` → **Режим разработчика** → **Загрузить распакованное** → папка `duck-mode`.

Версия для Safari лежит в папке `duck-mode-safari`.
