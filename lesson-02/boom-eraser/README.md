# Ластик-взрыватель 💣 (урок 2)

Включи режим и нажимай на любую часть сайта: картинку, текст, кнопку, рекламу.
Она затрясётся, взорвётся 💥 и исчезнет. Чтобы всё вернулось, обнови страницу.

Включить или выключить: значок расширения или **Alt + Shift + B**.

## Файлы
- `manifest.json` — «паспорт» расширения
- `background.js` — по нажатию на значок вставляет boom.js во вкладку
- `boom.js` — ловит нажатия раньше сайта (поэтому ссылки не открываются) и рисует взрыв

## Установка в Chrome
`chrome://extensions` → **Режим разработчика** → **Загрузить распакованное** → папка `boom-eraser`.

Версия для Safari лежит в папке `boom-eraser-safari`.
