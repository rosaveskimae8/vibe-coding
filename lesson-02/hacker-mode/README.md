# Режим хакера 💻 (урок 2)

Превращает любой сайт в хакерский терминал: чёрный фон, зелёный текст,
«цифровой дождь» из символов и окно, где печатается «взлом» сайта с надписью ACCESS GRANTED.
Всё понарошку: сайт не меняется, он просто перекрашивается у тебя на экране.

Нажми на значок расширения (или **Alt + Shift + H**), чтобы включить режим, и ещё раз, чтобы выключить.

## Файлы
- `manifest.json` — «паспорт» расширения
- `background.js` — по нажатию на значок вставляет hacker.js во вкладку
- `hacker.js` — перекрашивает страницу, рисует дождь из символов и печатает текст в терминале

## Установка в Chrome
`chrome://extensions` → **Режим разработчика** → **Загрузить распакованное** → папка `hacker-mode`.

Версия для Safari лежит в папке `hacker-mode-safari`.
