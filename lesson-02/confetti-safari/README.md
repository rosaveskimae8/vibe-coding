# Конфетти 🎉 для Safari (урок 2)

Юзерскрипт для приложения **Userscripts** (iPad, iPhone, Mac).
На каждой странице в правом нижнем углу появляется кнопка 🎉, а нажатие на неё запускает конфетти.

## Установка
1. Приложение **Userscripts** уже должно быть установлено и включено в Safari, как для Shorts Blocker.
2. Открой в Safari ссылку:
   https://raw.githubusercontent.com/rosaveskimae8/vibe-coding/main/lesson-02/confetti-safari/confetti.user.js
3. Значок пазла → **Userscripts** → **Install**.

## Выключить
Значок пазла → **Userscripts** → переключатель у **Конфетти**.
