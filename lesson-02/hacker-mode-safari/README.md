# Режим хакера 💻 для Safari (урок 2)

Юзерскрипт для приложения **Userscripts**. На каждом сайте в левом нижнем углу появляется кнопка 💻:
нажмёшь, и режим хакера включится, нажмёшь ещё раз, и он выключится.

## Установка
Открой в Safari ссылку и нажми значок пазла → **Userscripts** → **Install**:
https://raw.githubusercontent.com/rosaveskimae8/vibe-coding/main/lesson-02/hacker-mode-safari/hacker.user.js
