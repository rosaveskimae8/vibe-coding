# Shorts Blocker (урок 2)

Расширение для Chrome: обычные видео на YouTube смотреть можно,
а при открытии Shorts тебя перекидывает на главную страницу.
Нажми на значок расширения — там переключатель вкл/выкл (по умолчанию включено).

## Файлы
- `manifest.json` — «паспорт» расширения: имя, права, какие файлы запускать
- `content.js` — следит за адресом на YouTube и выкидывает с Shorts
- `popup.html` + `popup.js` — окошко с переключателем

## Как установить
1. Открой в Chrome `chrome://extensions`
2. Справа вверху включи **Режим разработчика**
3. Нажми **Загрузить распакованное** и выбери папку `shorts-blocker`
4. Закрепи значок (иконка пазла → булавка), чтобы переключатель был под рукой
