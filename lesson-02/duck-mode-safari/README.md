# Утиный режим 🦆 для Safari (урок 2)

Юзерскрипт для приложения **Userscripts**. Внизу слева появляется кнопка 🦆:
нажмёшь, и на сайт выйдет утка, нажмёшь ещё раз, и она уйдёт.
Включи звук на iPad, утка крякает!

## Установка
Открой в Safari ссылку и нажми значок пазла → **Userscripts** → **Install**:
https://raw.githubusercontent.com/rosaveskimae8/vibe-coding/main/lesson-02/duck-mode-safari/duck.user.js
