# Shorts Blocker для Safari (урок 2)

Та же идея, что и в Chrome-версии, но в виде **юзерскрипта**.
Настоящее расширение для Safari можно собрать только в Xcode на Mac,
поэтому здесь используется бесплатное приложение **Userscripts**.
Оно работает на iPad, iPhone и Mac.

## Как установить на iPad
1. Скачай из App Store бесплатное приложение **Userscripts** и открой его.
   Приложение попросит выбрать папку для скриптов, выбери любую.
2. Открой **Настройки → Приложения → Safari → Расширения → Userscripts**,
   включи его и разреши доступ ко всем сайтам (или хотя бы к youtube.com).
3. В Safari нажми на значок расширений (кусочек пазла в адресной строке) → **Userscripts** → **+** → новый JS-скрипт.
4. Вставь код из файла `shorts-blocker.user.js` и сохрани.

## Как выключить
Safari → значок пазла → **Userscripts** → переключатель у **Shorts Blocker**.
