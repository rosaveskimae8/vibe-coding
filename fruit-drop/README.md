# Fruit Drop 🍓

Игра в браузере: падающие фрукты, два одинаковых сливаются в следующий, побольше.

## Как запустить
Открыть `index.html` двойным щелчком — интернет не нужен.

## Правила
- Веди мышкой (или пальцем) и нажми, чтобы уронить. Клавиатура: ← → и пробел.
- 🫐 + 🫐 → 🍓 → 🍊 → 🍋 → 🍍 → 🍉, два арбуза дают +100 очков.
- Не дай предметам подняться выше красной линии.

## Что есть
- Подсказки: что сейчас в руке, что будет следующим, таблица слияний
- Три темы: фрукты, цветы, сладости
- Очки и рекорд для каждой темы

Сделано на HTML, CSS и JavaScript (canvas), без библиотек.
